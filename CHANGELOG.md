# Changelog

## 1.0.0 (2026-10-20)

First release published from GitHub.

### Features

* Widescreen loading screens for Anbennar: 32 upscaled loading screens in `gfx/loadingscreens`, replacing the originals (`replace_path`).
* Workshop thumbnail.
* Does not touch EU4 checksummed files, so it does not change the checksum or block achievements.
