**Anbennar's loading screens, made for widescreen monitors. Dwarven craftsmanship was not meant to be cropped by cowardly mortal aspect ratios.**

This mod replaces Anbennar's loading screens with upscaled versions that look good on 3440×1440 ultrawide displays, instead of a painting stretched or cut across your screen.

## What you get
- **Every loading screen** from the GitLab version of Anbennar, widened. If the image existed, the dwarves have probably widened it.
- **Works with** Anbennar: The Final Empire, from Steam or from GitLab.
- **Load order doesn't matter.** It only clashes with mods that also replace Anbennar's loading screens: if two dwarves swing picks at the same rock, one of them gets there first.
- **Pictures only:** it changes none of the files the game checks, so on its own it leaves the checksum as it is.

## You need
- **[Anbennar](https://steamcommunity.com/sharedfiles/filedetails/?id=1385440355)**, enabled in the same playset. The launcher loads this mod after it.
- **EU4 1.37** on Steam or GOG (on GOG, take the mod from GitHub).
- Recommended alongside: [P2KE Patch - Anbennar](https://steamcommunity.com/sharedfiles/filedetails/?id=3777997797), the Proper 2K UI interface for Anbennar on large screens.
