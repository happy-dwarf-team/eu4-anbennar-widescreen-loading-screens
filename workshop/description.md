**Anbennar's loading screens, made for widescreen monitors. Dwarven craftsmanship was not meant to be cropped by cowardly mortal aspect ratios.**

This mod replaces Anbennar's loading screens with upscaled versions that look good on 3440×1440 ultrawide displays, instead of a painting stretched or cut across your screen.

## What you get
- **Every loading screen** from the GitLab version of Anbennar, widened.
- **Works with** Anbennar: The Final Empire, from Steam or from GitLab.
- **Load order doesn't matter:** see the FAQ below.
- **Pictures only:** it changes none of the files the game checks, so on its own it leaves the checksum as it is.

## FAQ

### What load order should I use?
It does not matter. You cannot really control it from the launcher anyway, even if Paradox lets you pretend otherwise.

The only real way to influence load order is through properly set mod dependencies. If that is not done, EU4 resolves conflicts alphabetically. A beats Z. Dwarf law.

### Is it compatible with X?
Probably yes.

The only likely conflicts are with mods that also replace Anbennar loading screens. If two dwarves swing picks at the same rock, one of them gets there first.

### Why ultrawide loading screens?
Because 4:3 paintings stretched across a 21:9 monitor look like a kobold crime.

This mod attempts to correct that.
With hammer.
And discipline.
