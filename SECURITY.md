# Security policy

This is an EU4 mod with images only: it runs no code. Please report security problems privately, not in public issues.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/happy-dwarf-team/eu4-anbennar-widescreen-loading-screens/security/advisories/new).
Include the version, how to reproduce the problem, and what an attacker gains.

This is a volunteer project; reports are handled on a best-effort basis. We
will confirm the report, agree on a fix and a disclosure date with you, and
credit you in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.

## In scope

- The workflows: anything that lets a pull request reach a secret or a published Workshop item.
- Release integrity: a Workshop item that does not match the release it came from.

## Out of scope

- Vulnerabilities in Europa Universalis IV itself; report those to Paradox
  Interactive.
